## 3. 部署包与复现步骤

部署包 = 工作区 `deploy-free/`：

```
deploy-free/
├── src/                # Flask 应用（routes / templates / static / 各 AI 模块）
├── requirements.txt
├── init_db.py          # 建表 + 播种演示数据
└── start.sh            # 生产启动（见下）
```

`start.sh` 关键内容：

```bash
mkdir -p data
export FLASK_ENV=production
# SECRET_KEY 必须显式注入，且不得使用仓库/文档中出现过的任何值：
# session 是客户端签名 Cookie，密钥一旦出现在文档里就等于公开，可离线伪造管理员会话。
# 生成：python -c "import secrets;print(secrets.token_urlsafe(48))"
if [ -z "${SECRET_KEY:-}" ]; then
  echo "缺少 SECRET_KEY：请生成强随机值（≥16 位，禁用文档示例值）后再部署" >&2
  exit 1
fi
export DATABASE_URL="${DATABASE_URL:-sqlite:///$PWD/data/ican.db}"
export ICAN_INIT_CONFIRM=YES
export LLM_PROVIDER="${LLM_PROVIDER:-none}"
python init_db.py
exec python -m waitress --host=0.0.0.0 --port="${PORT:-8080}" --call src.app:create_app
```

复现命令（任意 Linux 沙箱 / 服务器通用）：

```bash
python3 -m pip install --no-cache-dir -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple
bash start.sh
```
