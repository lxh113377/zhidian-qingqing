# 库存与退换规范

## 一、日常盘点

- 闭店前按品类抽盘，每周全盘一次，核对系统库存与实际数量。
- 差异当日登记并复查，不跨周挂账；重大差异（超过 5 件或单价 500 元以上）立即上报店长。

## 二、差异排查顺序

1. 同款不同尺码是否串号。
2. 调货、退换、维修记录是否登记。
3. 残损商品是否已隔离未出库。
4. 试穿样衣是否归位。
5. 确认后修正系统并记录原因。

## 三、断码与调货

- 如实告知断码情况，给出替代色或相似款，不隐瞒、不用「最后一件」制造紧张感。
- 调货需确认尺码颜色、查询其他门店库存、登记顾客联系方式与预计到货时间。
- 到货第一时间通知顾客；超时主动说明并给出替代方案。

## 四、残损管理

- 发现破损、污渍、掉扣、抽丝立即下架，单独隔离并贴标识。
- 登记品名、尺码、残损原因与发现时间；可修复的送修，不可修复的按报废流程处理。
- 残损商品不得混入正常商品打折销售。

## 五、损耗率

损耗率 = 残损件数 ÷（库存剩余 + 残损件数），超过 5% 视为异常。

- 异常需回溯：陈列磨损、试穿损坏、仓储受潮、运输压损。
- 连续两周超标须提交改善措施（调整陈列方式、加强试穿引导、改善仓储）。

## 六、退换货政策

| 情形 | 处理 |
|------|------|
| 吊牌完整、未洗涤、无穿着痕迹 | 7 天内可退可换 |
| 已剪吊牌或已洗涤 | 不按正常退换，质量问题仍受理 |
| 质量问题（掉色、开线、缩水） | 无条件退换并致歉，同批次检查 |
| 特价商品 | 按成交前告知的规则执行 |
| 内衣等贴身类 | 非质量问题不退换（须成交前告知） |

退换政策必须在成交前明确告知，收据上标注，避免事后争议。

## 七、退货处理

- 退货商品经检查合格后重新上架，需重新整理熨烫并检查吊牌。
- 退货记录纳入品类分析，退货率高的款式反馈采购，减少下次订货。
