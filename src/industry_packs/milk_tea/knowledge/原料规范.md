# 原料储存与损耗控制规范

## 一、原料分类与储存

| 原料 | 储存条件 | 效期 | 备注 |
|------|----------|------|------|
| 鲜奶 | 冷藏 2–6℃ | 开封后 48h | 离地离墙存放 |
| 芒果 / 西柚 | 冷藏 | 2–3 天 | 切后果肉 4h 内用完 |
| 珍珠（煮好） | 保温 60℃+ | 4h | 超时报废 |
| 芋泥 | 冷藏 | 24h | 现做现用最佳 |
| 茶叶底 | 冷藏 | 当日 | 不过夜 |
| 柠檬 | 冷藏 | 5 天 | 切片后 4h 用完 |

## 二、配比标准

- 珍珠奶茶：茶底 : 奶 = 3 : 1，珍珠 50g/杯
- 杨枝甘露：芒果 120g + 西柚 30g + 西米 40g + 椰浆 30ml
- 烧仙草：仙草冻 150g + 鲜奶 200ml
- 芋泥波波：芋泥 80g + 鲜奶 200ml + 波波 40g

## 三、损耗控制

- 按近 7 天销量动态备货，易损原料（鲜果/鲜奶）少备勤补。
- 每日营业结束盘点剩余量与损耗量，损耗率 = 损耗量 / (剩余量 + 损耗量)。
- **损耗率超过 15% 视为异常**，需查明原因（备货过多 / 储存不当 / 操作浪费）。
- 原料异常（变色、异味、胀包）立即停用并上报，禁止继续使用。

## 四、卫生操作

- 操作前洗手消毒，佩戴口罩与帽。
- 生熟分开，刀具砧板专用。
- 操作台每班次清洁消毒，地面无积水。
- 过敏提示：含芒果、芋泥、奶制品的饮品需主动告知顾客。

## 五、到货验收

- 验收四看：看数量（与送货单一致）、看外观（无腐烂碰伤）、闻气味（无异味发酵味）、看温度（冷链原料到店 ≤8℃）。
- 抽检成熟度：芒果按压微软有弹性为佳，过硬需常温催熟 1-2 天，过软立即优先使用。
- 不合格原料当场拒收并拍照留证；已入库后发现问题，单独隔离贴「禁用」标识并上报店长。

## 六、盘点与损耗报表

- 每日打烊前 30 分钟盘点：记录剩余量、损耗量、报废原因（变质／操作失误／过期）。
- 损耗率 = 损耗量 ÷（剩余量 + 损耗量）；连续 3 天超过 15% 必须提交原因分析与改善措施。
- 损耗登记必须真实：不得把卖不掉的原料记成「顾客退货」或直接不登记。

## 七、常见异常处置

| 异常 | 处置 |
|------|------|
| 冷藏柜报警／停机 | 立即转移原料至备用冰柜，报修并记录时长 |
| 珍珠发硬发酸 | 整批报废，不得回锅或加糖掩盖 |
| 鲜奶临期 | 优先用于当日出品，到期未用完即报废 |
| 鲜果局部腐烂 | 整颗报废，禁止切掉坏处继续使用 |

## 八、每日动作清单

- 开店：查温度 → 验收到货 → 检查效期标识。
- 营业中：每 2 小时巡检原料状态，及时补充冰水与煮制珍珠。
- 打烊：盘点 → 登记损耗 → 清理操作台 → 关闭设备电源。
