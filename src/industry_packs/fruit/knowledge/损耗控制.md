# 损耗控制规范

## 一、损耗口径

- 损耗率 = 损耗量 ÷（剩余量 + 损耗量），每日闭店盘点后核算。
- **损耗率超过 8% 视为异常**（生鲜行业口径严于一般零售），需当日记原因：
  进货过量 / 冷藏不当 / 翻检不及时 / 顾客挑拣损伤。

## 二、分级处置

| 果品状态 | 处置方式 |
|----------|----------|
| 完好 | 正价售卖 |
| 轻微压伤 / 斑点 | 挑出做果切盒或下午特价（贴「当日鲜切」标签） |
| 过熟但可食 | 降价促销区，先到先得 |
| 霉变 / 异味 | 立即装袋废弃，称重登记报损，禁止混卖 |

## 三、预防措施

- 少备勤补：按近 7 天销量进货，易损品（草莓、桑葚）宁少勿多。
- 先进先出：补货必翻堆，短效期永远在前排。
- 分级陈列：精品区 / 常规区 / 促销区分开，避免好果坏果混放传染。
- 下午 17:00 巡场：对次鲜果主动打折，赶在闭店前消化。

## 四、报损登记

- 每笔报损称重记录（品类 + 重量 + 原因），月末汇总分析损耗结构。
- 报损集中的品类要回溯：是订货问题还是储存问题，调整进货策略。
- 禁止把报损果二次上架或私自拿走，一律登记。

## 五、损耗四段定位

| 环节 | 常见损耗 | 改善动作 |
|------|---------|---------|
| 到货验收 | 压伤、碰伤 | 当场挑除、拒收不合格批次 |
| 储存 | 温度不当、乙烯催熟 | 分区存放、隔离乙烯释放果 |
| 陈列 | 翻拣损伤 | 减少翻拣、用样品代替反复挑拣 |
| 销售末端 | 卖剩报损 | 动态订货、临近打烊小份促销 |

## 六、动态订货方法

- 以近 7 天同品类日均销量为基线；工作日按下限，周末与节前按 1.2-1.5 倍备货。
- 易损品类（草莓、蓝莓、鲜切）少备勤补；耐储品类（苹果、橙）可适度备货。
- 连续 3 天损耗率超包阈值（见 pack.json formula_params.waste_rate_threshold，当前 8%）必须提交原因分析与订货调整方案。

## 七、报损红线

- 报损必须称重登记：品类 + 重量 + 原因 + 经办人。
- 禁止腐烂果二次上架、切掉坏部继续售卖、私自带走处理。
- 报损数据月末汇总，分析损耗结构并输出下月改善动作。
