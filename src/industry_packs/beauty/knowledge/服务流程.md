# 服务流程规范

## 一、四段标准流程

沟通确认 → 操作施工 → 过程检查 → 交付复检。

四段缺一不可：跳过沟通易返工，跳过检查易出事故，跳过复检易产生投诉。

## 二、洗剪吹六步

迎宾入座 → 需求沟通 → 洗发 → 剪发 → 吹整造型 → 复检交付。

- 迎宾后 3 分钟内必须有人接待并说明预计等待时间。
- 交付前请顾客照镜确认，满意后再结账。

## 三、剪发沟通清单

1. 长度：剪多少厘米，是否保留可扎发。
2. 层次与厚薄：是否打薄、要不要留重量线。
3. 刘海：长度、厚度、是否要覆盖额头。
4. 打理习惯：日常是否愿意吹造型。
5. 禁忌项：顾客明确不接受的处理方式。

沟通后复述一遍并请顾客确认，避免「剪完才发现不一样」。

## 四、烫染流程

发质检测 → 方案报价 → 过敏测试 → 施工 → 节点检查 → 定型 → 交付。

- 上色后 10 分钟、20 分钟各检查一次发根上色情况。
- 出现发烫、刺痛等异常立即冲洗并停止操作。
- 烫发后 48 小时内不洗头，一周内不做二次烫染。

## 五、美甲流程

修形 → 去死皮 → 打磨 → 清洁除尘 → 上底胶与色胶 → 封层照灯。

- 打磨只做轻度处理，同一甲面不反复大力打磨。
- 卸甲使用专用卸甲液，禁止硬撕硬抠。

## 六、顾客不满意处置

倾听 → 复述诉求 → 判断原因 → 当场复修 → 升级资深技师 → 协商补偿。

- 全程不辩解、不推诿、不指责顾客。
- 属沟通偏差的免费复修；属技术问题的由资深技师接手。

## 七、收尾清单

1. 带顾客确认效果。2. 说明护理与打理方法。
3. 提示下次护理周期。4. 结账并引导评价。
5. 清理工位、器具归位并完成消毒。

## 八、等待与排队管理

- 顾客到店后 3 分钟内接待并告知预计等待时长；等待超过 10 分钟主动解释原因。
- 有预约的顾客优先安排；临时到店顾客如实说明需要等待的时间，不虚报「马上就好」。
- 高峰期可提供茶水与杂志，或引导顾客先做头皮检测、养护咨询等无需工位的项目。

## 九、复检标准

| 项目 | 复检要点 |
|------|---------|
| 剪发 | 左右对称、层次过渡自然、刘海长度一致 |
| 染发 | 发根无色差、颈部与耳后无残留染膏 |
| 烫发 | 卷度均匀、发尾不焦、无明显药水味残留 |
| 美甲 | 甲面平整无气泡、边缘无溢胶、十指一致 |

复检由操作技师自检 + 值班技师抽检，不合格当场返工，不带问题交客。
