# 洗护流程规范

## 一、五步标准流程

接宠检查 → 梳理去结 → 温水洗护 → 彻底吹干 → 复检交付。

每一步发现异常都要记录并告知主人，异常未确认前不进入下一步。

## 二、接宠检查清单

| 检查项 | 观察内容 |
|--------|---------|
| 皮肤 | 红肿、结痂、脱毛、寄生虫 |
| 耳道 | 异味、黑褐色污垢、频繁抓耳 |
| 指甲 | 长度、是否劈裂、有无血线外露 |
| 肛门腺 | 是否肿胀、是否需要挤压 |
| 牙齿口腔 | 口臭、牙结石、牙龈红肿 |

同时询问主人近期健康、用药与疫苗情况，并记录进服务单。

## 三、洗护标准

- 水温 36-38℃（接近宠物体温），冬季可略高 1-2℃。
- 使用宠物专用浴液，避免入眼入耳；洗后彻底冲净泡沫，残留会引发瘙痒。
- 打结毛发先用手分层拆结，再由毛尖向毛根梳理；严重打结与主人沟通后剪除，不硬扯。

## 四、吹干标准

- 吹干要求毛根无潮气，腋下、腹部、耳后、脚底为易漏部位。
- 长毛犬需边吹边梳，防止吹干过程中形成新打结。
- 吹干是硬标准：未吹干不交付，残留潮气会引发皮肤病与异味。

## 五、猫咪洗护要点

- 独立安静区域、减少束缚与噪音，尽量缩短整体时长。
- 不强制吹风；极度应激的猫改用免洗产品，或与主人约定分次完成。

## 六、工具清洁与消毒

| 器具 | 处理方式 | 频次 |
|------|---------|------|
| 剪刀、梳子 | 清除毛发 + 酒精消毒 | 一客一消毒 |
| 浴缸、台面 | 冲洗 + 消毒液擦拭 | 一客一消毒 |
| 毛巾 | 高温消毒（80℃ 以上 15 分钟） | 一客一换 |
| 航空箱 | 擦拭消毒、通风晾干 | 一客一消毒 |

## 七、交付与护理提醒

- 当面向主人展示皮肤、耳道、指甲处理结果与造型效果。
- 说明发现的问题与建议（如皮肤异常建议就医），不隐瞒也不夸大。
- 提醒 24 小时内避免洗澡与剧烈活动，长毛犬注意每日梳理。
