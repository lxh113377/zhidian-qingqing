# 健康与安全规范

## 一、疫苗门槛

- 犬只：需完成犬瘟、细小、狂犬疫苗接种并提供记录；幼犬未完成全程接种不接洗护与寄养。
- 猫咪：需完成猫三联接种；未接种或记录不全的婉拒服务并建议先接种。
- 疫苗本照片可存档，服务前核对有效期，过期视为未接种。

## 二、健康筛查

| 异常情况 | 处置 |
|---------|------|
| 皮肤病、结痂、脱毛 | 暂停服务、隔离、建议就医 |
| 寄生虫（跳蚤、蜱虫） | 不接单，环境与器具单独消毒 |
| 咳嗽、流鼻涕、腹泻 | 不接单，建议先就医排查传染病 |
| 开放性伤口 | 避开伤口或暂停服务，按主人意见处理 |
| 老年宠物慢性病 | 需主人提供兽医意见，缩短流程 |

## 三、应激识别与处置

- 表现：剧烈发抖、张口喘、呕吐、失禁、僵直、突然攻击。
- 处置：立即停止操作 → 移至安静环境 → 减少束缚与噪音 → 观察缓解情况 → 联系主人。
- 不强行继续操作，应激造成的伤害远大于一次服务收入。

## 四、操作安全

- 保定以温和、最小约束为原则，托住胸腹与后肢，禁止提拉前肢、拽尾巴、按压气管。
- 剪指甲只剪透明部分三分之一，靠近血线处留出余量。
- 药浴严格按说明配比，操作人员戴手套、保持通风，药浴后观察 30 分钟。

## 五、事故应急

| 事故 | 处置 |
|------|------|
| 剪甲出血 | 止血粉按压止血，安抚并告知主人 |
| 水入耳道 | 干棉球吸水 + 专用耳液清洁，观察甩头抓耳 |
| 员工被咬伤 | 清洗伤口 15 分钟并消毒，就医评估疫苗 |
| 过敏或抽搐 | 立即停止、保持呼吸道通畅、就近送医 |

- 所有事故保留记录、照片与当事人信息，当日上报店长，24 小时内回访。

## 六、隔离与消毒

- 疑似传染病宠物单独通道进出，接触区域与器具即刻消毒。
- 消毒液当日现配现用，标注配制时间；含氯消毒液与酒精分柜存放。

## 七、拒单红线

未接种疫苗、疑似传染病、严重心脏或呼吸疾病、极端攻击性、重度应激体质，一律不接单并向主人说明原因与替代方案。
