# 客诉处理规范

## 一、处理三原则

1. **先致歉不辩解**：「给您带来不好的体验，非常抱歉。」
2. **先受理再走流程**：不当场拒绝，先把顾客诉求完整听完。
3. **当场给结论或给时限**：能解决的当场解决；不能的明确「24 小时内给您答复」。

## 二、常见客诉应对

| 场景 | 应对要点 |
|------|----------|
| 服务态度差 | 道歉 + 了解诉求 + 补救（优惠券 / 小礼品），事后上报记录 |
| 商品质量问题 | 无条件退换，致歉，同批次下架检查 |
| 非质量退换 | 按门店政策（未拆封 7 天），先受理再走流程 |
| 找零 / 多扣款 | 当场核对收银记录，属实立即退还并致歉 |
| 外卖差评 | 当日回复安抚 + 补偿方案，绝不与顾客线上争执 |

## 三、升级客诉

- 顾客情绪激动或要求超出权限：第一时间请店长接手，自己留在现场协助。
- 涉及食品安全（异物、变质）：保护现场商品与监控记录，登记上报，不私了不承诺。
- 24 小时内回访处理结果，记录复盘，同类问题出预防措施。

## 四、记录与复盘

- 每笔客诉登记：时间、顾客诉求、处理方式、结果、是否升级。
- 每周复盘客诉 Top 场景，针对高频问题出话术或流程改进。

## 五、常见客诉处置口径

| 客诉类型 | 处置口径 |
|---------|---------|
| 食品变质／过期 | 全额退款 + 按规定赔偿 + 同批次下架 |
| 标价与结账不一致 | 按低价结算 + 更正价签与系统 |
| 服务态度 | 先道歉 + 补救（优惠券／小礼品）+ 记录 |
| 排队过久 | 致歉 + 引导自助结账 + 增开收银位 |

## 六、店内安全事件

- 顾客摔倒：先关心伤情，不随意搬动，必要时拨打 120；保留现场与监控。
- 地面湿滑：立即放置警示牌并清理，事后排查漏水与清洁流程。
- 所有安全事件当日登记时间、地点、原因、处置人。

## 七、冲突升级红线

- 不与顾客争执对错、不作无权限承诺（免单、赔偿、公开道歉）。
- 遇醉酒或闹事顾客保持安全距离，请店长出面，必要时报警。
- 涉及食品安全与人身安全，一律保护现场、留存监控、上报。
